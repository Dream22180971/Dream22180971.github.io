# Sean Walter · 数字观测站

基于 GitHub Pages 的静态个人导航站，包含空间目录、精选项目与精选文章。默认中文，右上角可切换英文，语言偏好保存在浏览器本地。文章链接指向原文，原文可能为中文。

## 本地预览

在本目录运行：

```bash
python -m http.server 8000
```

访问 http://localhost:8000/。无需安装依赖或构建。

## 内容维护

- `index.html`：布局、网站入口、动画记忆博物馆精选展示、项目和文章。三个网站入口同时保留在首屏轨道和页脚。
- `language.js`：中文文本与英文译文。新增或修改中文内容时，同时更新对应翻译；相同的中文文本共用一个译文。
- `favicon.svg`：浏览器标签页图标，使用星球与轨道图形。
- `assets/museum-home.webp`：动画记忆博物馆线上首页截图，精选区以大画面展示；网站改版后可更新。
- 页脚年份由 `footer.js` 根据访客设备时间自动更新。
- 文章和项目为手动精选，不会自动同步。请定期检查链接。
- 首屏网站节点由 `galaxy.js` 均匀分布并绕中心运行；鼠标悬停或键盘聚焦可见简介，节点暂停，减少动态效果时静止。新增节点时在 `.scene` 添加 `.point`、更新翻译及 `galaxy.js` 中的域名简介，并更新页面脚本版本参数。
- 首屏星野和中心天体由 CSS 绘制；天体缓慢浮动，减少动态效果时静止。
- `galaxy.js` 使用 Canvas 绘制动态粒子；离开可视区域或页面隐藏时停止动画，减少动态效果时展示静态画面。
- 移动端入口采用至少 44px 的触控高度；链接支持键盘焦点与悬停反馈。
- 导航栏滚动时固定在顶部，使用半透明模糊背景；分区锚点保留顶部间距。
- 各内容区使用深空色调与背景层，轨道入口保留直接跳转。
- `sections-design.css` 与 `sections-motion.js` 控制后续内容区的布局和滚动动效；减少动态效果时关闭运动。
- 标题光晕、按钮光束和底部文字粒子使用 CSS 实现，并遵循减少动态效果设置。

## 发布

将文件提交并推送至 GitHub 仓库的 `main` 分支，在仓库 Settings → Pages 中选择 Deploy from a branch、`main` 和 `/ (root)`，等待部署完成。实际是否部署以 GitHub Pages 的状态为准。
